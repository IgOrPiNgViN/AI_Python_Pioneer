Материалы курса «Инженерия ИИ» на Python для школьников 8–9 классов.

---

## Быстрый старт

1. [Как пользоваться Google Colab](ИНСТРУКЦИЯ_GOOGLE_COLAB.md) — где запускать код, ничего не устанавливая  
2. Открой нужный урок ссылкой **«Открыть»** в таблице ниже — он запустится в Colab  
3. **Файл → Сохранить копию на Диске** — работай только в своей копии  
4. Иди по порядку, начиная с [Урока 1](уроки/1_старт_и_инструменты/урок_01_что_такое_ИИ.ipynb); краткое содержание всего курса — в [конспекте](конспект_курса.ipynb)

## Описание курса

- **36 занятий** — раз в неделю по 60 минут, с 24.09.2026 по 27.05.2027  
- Python → работа с данными → машинное обучение → ИИ-приложения → итоговый проект  
- Каждый урок — Jupyter-ноутбук: теория маленькими шагами, примеры кода, практика с решениями под спойлером, домашнее задание и самопроверка  
- **Тема в тему:** в каждом уроке используется только то, что уже изучено; в начале ноутбука указано, на какие уроки он опирается  
- ИИ-помощник с урока 2 — инструмент для объяснений и поиска ошибок, а не «сделай всё за меня»

## Как пользоваться уроками

1. Читай текстовые ячейки сверху вниз и запускай ячейки кода по порядку (`Shift + Enter`).  
2. Меняй числа и текст в примерах и запускай снова — так быстрее всего понятно, что делает код.  
3. Задачи практики сначала решай сам; решение спрятано под спойлером «Решение».  
4. Ответы на вопросы пиши прямо в текстовых ячейках ноутбука.  
5. Иди по порядку: каждый урок опирается только на предыдущие.  
6. Уроки 14–16 приходятся на каникулы — это повторение и тренажёры, их пропуск не мешает следующим урокам.
