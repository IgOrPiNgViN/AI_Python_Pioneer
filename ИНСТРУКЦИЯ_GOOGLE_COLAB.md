# Инструкция: Google Colab

Google Colaboratory (Colab) — бесплатная облачная среда для запуска кода на Python прямо в браузере. Устанавливать Python на компьютер **не обязательно**.

Официальный сайт: [https://colab.research.google.com](https://colab.research.google.com)

---

## 1. Что нужно перед стартом

1. Аккаунт Google (Gmail / школьный аккаунт Google).
2. Браузер: Chrome, Edge, Firefox или Яндекс.Браузер.
3. Стабильный интернет.
4. На занятии удобно иметь наушники, если в классе шумно — Colab звук не требует.

---

## 2. Первый запуск (пошагово)

1. Открой [https://colab.research.google.com](https://colab.research.google.com).
2. Войди в аккаунт Google.
3. Нажми **Файл → Создать блокнот** (или *New notebook*).
4. Сверху можно переименовать файл: клик по названию `Без названия.ipynb` → например `Урок_03_Python.ipynb`.
5. В ячейке напиши код, например:

```python
print("Привет, инженерия ИИ!")
```

6. Запусти ячейку:
   - кнопка ▶ слева от ячейки, или
   - `Shift + Enter` (запуск + переход к следующей), или
   - `Ctrl + Enter` (запуск без перехода).

7. При первом запуске Colab подключит **рантайм** (виртуальную машину) — подожди 10–30 секунд.

---

## 3. Как устроен блокнот

| Элемент | Зачем |
|--------|--------|
| **Ячейка кода** | Пишешь и запускаешь Python |
| **Текстовая ячейка (Markdown)** | Заметки, заголовки, ответы на вопросы |
| **▶ Run** | Выполнить ячейку |
| **+ Код / + Текст** | Добавить новую ячейку |
| Меню **Среда выполнения** | Перезапуск, смена типа рантайма |

Полезные сочетания клавиш:

- `Shift + Enter` — выполнить и перейти дальше  
- `Ctrl + M` затем `B` — новая ячейка ниже  
- `Ctrl + M` затем `A` — новая ячейка выше  
- `Ctrl + M` затем `D` — удалить ячейку  

---

## 4. Как сохранить работу

Colab сохраняет файлы на **Google Диск**.

1. Убедись, что вошёл в свой аккаунт.
2. Обычно автосохранение уже включено.
3. Проверь: **Файл → Сохранить копию на Диске**.
4. На Диске появится папка `Colab Notebooks`.

**Рекомендация:** создай папку `Инженерия_ИИ_2026` и складывай туда копии уроков.

Также можно:

- **Файл → Скачать → .ipynb** — скачать на компьютер;
- **Файл → Скачать → .py** — только код без ячеек.

## 5. Как открыть урок с диска или по ссылке

### С Google Диска

1. Открой [Google Диск](https://drive.google.com).
2. Найди файл `.ipynb`.
3. ПКМ → **Открыть с помощью → Google Colaboratory**.

### Прямо с GitHub (проще всего)

Все уроки курса лежат в репозитории [AI_Python_Pioneer](https://github.com/IgOrPiNgViN/AI_Python_Pioneer).

1. В [README курса](https://github.com/IgOrPiNgViN/AI_Python_Pioneer#readme) нажми ссылку **«Открыть»** в строке нужного урока — урок сразу откроется в Colab.
2. Или в Colab: **Файл → Открыть блокнот → вкладка GitHub**, вставь `IgOrPiNgViN/AI_Python_Pioneer` и выбери урок.
3. Нажми **Файл → Сохранить копию на Диске** — и работай в своей копии.

### По ссылке от преподавателя

1. Открой ссылку.
2. Нажми **Файл → Сохранить копию на Диске** — чтобы править **свою** копию, а не общую.

> Важно: если править общий файл без копии, можно мешать другим или потерять доступ к правкам.

## 6. Загрузка данных (CSV и файлы)

### Вариант А — загрузить с компьютера

```python
from google.colab import files
uploaded = files.upload()  # выбери файл в окне
```

### Вариант Б — с Google Диска

```python
from google.colab import drive
drive.mount('/content/drive')
```

После этого путь к файлам будет вида:

```text
/content/drive/MyDrive/Инженерия_ИИ_2026/data.csv
```

## 7. Установка библиотек

Многие библиотеки уже есть (`numpy`, `pandas`, `matplotlib`, `sklearn`).

Если чего-то нет:

```python
!pip install имя_библиотеки
```

Пример:

```python
!pip install seaborn
```

После установки иногда нужно **Среда выполнения → Перезапустить среду выполнения**.

---

## 8. Если что-то сломалось

| Проблема | Что сделать |
|----------|-------------|
| Код не запускается, крутится долго | **Среда выполнения → Прервать выполнение** |
| Странные ошибки «как будто всё сломалось» | **Среда выполнения → Перезапустить среду выполнения** |
| «Сеанс завершён» / отключилось | Просто снова запусти ячейку — Colab переподключится |
| Забыл сохранить | Проверь Диск и **Историю версий** файла |
| Ошибка про пакет | Установи через `!pip install ...` и перезапусти среду |

Перезапуск среды **стирает переменные в памяти** — ячейки нужно выполнить снова сверху вниз.

## 9. Правила работы с ИИ-агентами в Colab (курс)

С урока 2 действует правило:

1. Сначала попробуй сам (прочитай условие, напиши черновик).
2. Агента проси **объяснить**, **найти ошибку**, **подсказать идею** — не «сделай всю работу».
3. Вставь в промпт: условие задачи, свой код, текст ошибки.
4. Любой код от агента **прочитай и запусти сам**. Если не понимаешь строку — спроси «объясни эту строку».
5. На самостоятельных и контрольной — следуй указаниям преподавателя (где агент разрешён / запрещён).

Шаблон хорошего запроса:

```text
Роль: ты помощник ученика 8–9 класса по Python.
Контекст: вот мой код и ошибка.
Задача: объясни причину ошибки и что исправить. Не пиши всё решение целиком, если можно обойтись подсказкой.
Формат: 1) причина, 2) что поменять, 3) короткий пример.
Ограничение: уровень — новичок, без сложных терминов без пояснения.
```
